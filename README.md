## Game Name

### UNO Show'Em No Mercy

UNO Show'Em No Mercy is a browser-based card game created using
HTML, CSS, and JavaScript.

The player enters their name and plays against two computer opponents.

The game includes different UNO cards, special cards, turn management,
drawing cards, attack stacking, hand swapping, and the Mercy Rule.

### Why I Chose This Game

I chose UNO because it is a fun and familiar card game.

It was also a good choice for practicing JavaScript because the game
requires different programming concepts such as:

- Arrays
- Objects
- Classes
- Functions
- Conditional statements
- DOM manipulation
- Event listeners
- Game state
- Player turns
- Computer player logic

Building the game allowed me to practice these concepts in a real
interactive project instead of only using small examples.

# Getting Started

## Play the Game

The game is deployed using GitHub Pages.

**Live Game:**

https://hasan-mohammed-s.github.io/UnoNoMercy-project/

## How to Play

1. Open the game using the link above.
2. Enter your name in the name field.
3. Click **Start Game**.
4. The game will deal cards to the player and the two computer opponents.
5. During your turn, choose a playable card from your hand.
6. A card can normally be played when it matches the current color
   or the current number/type.
7. If you cannot play a card, use the draw pile.
8. Special cards have different effects on the game.
9. The computer players will automatically take their turns.
10. Continue playing until a player wins or the Mercy Rule eliminates
    a player.

## Main Game Features

The game includes:

- One human player.
- Two computer opponents.
- Seven cards dealt to each player.
- Card matching by color and number.
- Draw pile.
- Discard pile.
- Player turn management.
- Computer turn management.
- Special card effects.
- Attack cards.
- Attack stacking.
- Hand swapping.
- Skip/Stop effects.
- Play Again effects.
- Play All effects.
- Wild cards.
- Mercy Rule.
- Winner message.
- Restart game option.
